📡 Transferencia de archivos P2P (misma Wi‑Fi)

Sin conexión

1. ¿Qué rol tiene este PC?

Abre este mismo archivo en ambos PCs. Uno crea la conexión y el otro se une. Los códigos se intercambian una sola vez (por chat, correo, Teams, etc.). Los archivos viajan directo entre los PCs por la red local, sin servidor.

PC A · Crear conexión

  1. Copia el código de invitación y envíalo al PC B.
  2. Pega aquí el código de respuesta que te devuelva el PC B y presiona Conectar.

PC B · Unirse

  1. Pega el código de invitación del PC A y presiona Generar respuesta.
  2. Copia el código de respuesta y envíalo al PC A.

Enviar archivos

Arrastra archivos aquí o haz clic para seleccionar

Archivos recibidos

Al terminar cada archivo aparece el enlace para guardarlo.

Notas

  • Funciona en Chrome, Edge y Firefox recientes. No requiere internet; solo la misma red.
  • Si no conecta, la red puede bloquear tráfico entre equipos (aislamiento de clientes, común en Wi‑Fi corporativas o de invitados).
  • Ambos PCs deben mantener esta página abierta durante la transferencia.
